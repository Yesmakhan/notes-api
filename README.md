# Notes API

A simple backend project built with FastAPI.

## About the project

This is a basic Notes API created for backend learning and practice.  
The project supports CRUD operations for notes and uses in-memory storage.

At the current stage, the API can:
- get all notes
- get one note by id
- create a new note
- update a note
- delete a note

## Tech stack

- Python
- FastAPI
- Uvicorn
- Pydantic
